# Theming and Matugen

Adwisp is intended to support palettes generated by [Matugen](https://github.com/InioX/matugen). Theme integration is still in progress; the current OSD prototype uses fixed fallback colors.

## Planned palette format

The first parser will support a simple UTF-8 `key=value` file, for example:

```ini
background=#1d1a20
surface=#29252d
text=#f5eff7
muted=#cac3cf
accent=#d0bcff
on_accent=#381e72
```

Hex colors will be normalized by the parser before being converted to ASS color notation. Invalid or missing values should fall back safely to the built-in palette.

## Live reload design

The target is to reload colors only when the palette changes, not on every frame. A reload command and/or a file-watch integration may be used; any watcher must be optional and should not add idle polling overhead. Until this lands, restart mpv after changing a palette.

## Design principles

- Maintain readable contrast in both light and dark palettes.
- Keep semantic color roles separate from specific widgets.
- Cache parsed palette data and avoid rebuilding unchanged styles.
- Never invoke Matugen on every redraw.
